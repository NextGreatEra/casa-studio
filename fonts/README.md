# Fonts

OFL files used by the 7×10 interior renderer:

- `Literata-Regular.ttf` (body)
- `SourceSans3-Regular.ttf` (labels)

Run `npm run fonts` (or `npm run preflight`) to download them. Do not substitute Helvetica or Times — those unembedded Type 1 fonts are the current KDP blocker on the existing ReportLab masters.
